# Operating Context for Routines

## Identity & audience
This repository powers automated routines for an Akbank senior strategy
professional. All deliverables target executive-level audiences.

## Akbank Brand Spec — apply to all HTML/visual outputs

### Colors
- Primary Red: #E0362A
- Dark Red: #B82820
- Light Red: #FF6B5E
- Charcoal: #1A1A1A
- Light BG: #F5F5F5
- Border: #E8E8E8
- Body Text: #6B7280
- Contrast Blue (data only): #2563EB

### Typography
- Headlines: Plus Jakarta Sans, Bold, sentence case
- Body: Plus Jakarta Sans or Inter, 15px, line-height 1.6
- NEVER serifs, scripts, or decorative fonts

### Layout
- White-dominant, generous whitespace
- Red as accent (CTAs, dividers, key metrics) — never as background flood
- Cards: #F5F5F5 bg, 8px radius, subtle border
- Grid-based, no decorative flourishes
- Data-forward: KPIs visually prominent

### Tone
- Executive, confident, data-driven
- No filler or buzzwords
- Cite every claim with source + date
- 3-year strategic horizon when relevant

## Universal output rules
- Verify every fact via web search before stating it
- Paraphrase sources; never quote more than one short sentence per source
- Never speculate beyond reported facts
- Never recommend trades, prices, or investment positions
- Use exact Turkish company branding (İş Bankası, not "Is Bank")
- TRY values include USD equivalent at the day's rate
